## Vocal Teleprompter 1.7.0

**Live frosted glass on Windows.** What shows through the prompter is now blurred live, as on
GNOME: a video or a window you drag behind it stays soft at once, and only the letters take a
moment to pick their new colors. And they no longer blink while they do.

### Install

**Windows:** if you have 1.2.0 or later, the app offers this update by itself: accept it
and you're done. Otherwise download `vocal-teleprompter_1.7.0_x64-setup.exe` (or the
`.msi`) and run it.

> Windows SmartScreen may warn you because the installer is not code-signed yet:
> **More info → Run anyway**.

**Linux:** download `VocalTeleprompter.AppImage` (make it executable and run it), or the
`.deb` or `.rpm` for your distribution. On GNOME, also install the extension from this
release:

```sh
gnome-extensions install --force vocal-teleprompter@faure-galliard.github.io.shell-extension.zip
# log out and back in, then
gnome-extensions enable vocal-teleprompter@faure-galliard.github.io
```

### What's new

**🧊 Live glass on Windows**
- The glass behind the window is drawn live instead of from pictures taken every so often:
  it follows a video, a slide transition or a dragged window at once.
- It keeps going while you click your slides: it never turns gray when the prompter loses
  the focus.
- On Windows 11 it blurs as much as the softening asks, like on GNOME. Windows 10 blurs at
  its own strength.
- Opening or closing the toolbar no longer makes the glass blink: as on Linux, the window
  keeps the toolbar's room below the prompter, and clicks there reach what is behind it.

**🎨 Letters that read over anything, more calmly**
- The letters and the window's edge no longer blink each time the prompter looks behind
  itself, and new colors fade in.
- The prompter only looks behind itself when something there changed, so a still screen
  costs nothing and a video behind it is followed closely.
- Visible in recordings, it no longer looks behind itself while you drag it, only once you
  let go, and never behind the toolbar's room.

**Also**
- Fixed a crash looking behind the window while it is visible in recordings.
- A plainer README, with the Linux downloads next to the Windows one.

### Known issues

- The GNOME Shell extension is made for GNOME 51. Without it, or on other desktops, the
  prompter works with a plain background, and is not kept above other windows or hidden
  from screen sharing.
- Windows 10 before version 1809 keeps the glass drawn from pictures.
- Hiding from screen capture needs Windows 10 version 2004 or newer.
