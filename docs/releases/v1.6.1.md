## Vocal Teleprompter 1.6.1

**Now on Linux too, and with a library of your scripts.** The prompter runs natively on
GNOME (Wayland), with the same see-through glass, letters that read over anything and
hiding from screen sharing as on Windows. On every system, your scripts are now kept in a
library you can switch between.

### Install

**Windows:** if you have 1.2.0 or later, the app offers this update by itself: accept it
and you're done. Otherwise download `vocal-teleprompter_1.6.1_x64-setup.exe` (or the
`.msi`) and run it.

> Windows SmartScreen may warn you because the installer is not code-signed yet:
> **More info → Run anyway**.

**Linux:** download `VocalTeleprompter.AppImage` (make it executable and run it), or the
`.deb` or `.rpm` for your distribution. On GNOME, also install the extension from this
release, which lets the prompter see behind its window, stay above other windows and hide
from screen sharing:

```sh
gnome-extensions install --force vocal-teleprompter@faure-galliard.github.io.shell-extension.zip
# log out and back in, then
gnome-extensions enable vocal-teleprompter@faure-galliard.github.io
```

### What's new

**🐧 Linux**
- Runs natively on Wayland, with its icon in the dock and in Alt+Tab, and a tray icon where
  the desktop shows one.
- With the GNOME Shell extension:
  - Frosted glass drawn live by GNOME itself, so it follows a video or a dragged window at
    once.
  - Every letter colored to read over what is behind it, as on Windows. The colors follow
    clicks, keys and mouse movement anywhere, and a video behind the window.
  - The window stays above other windows and out of screenshots.
- The toolbar opens at once: the window keeps room for it below the text, and clicks on
  that empty room go through to what is behind.
- Experimental: a screen sharing portal that leaves the prompter out of a full-screen share
  in Meet and other browser calls. It replaces GNOME's screen sharing for your user, so it
  is installed by hand: see `linux/screencast-portal/README.md` in the repository.

**📚 A library of your scripts**
- The script menu lists your scripts, latest first, to switch between them, with a
  new-script entry and a way to delete one.
- The script on screen is saved as you edit it, so switching never loses anything.
- Pasting, importing or getting a script from an assistant starts a new one instead of
  replacing what you had. The script you had before this version becomes the first one in
  the library.

**🤖 Assistants (MCP)**
- Assistants can list your saved scripts and open one, and a script they write is saved as
  a new one.
- They can also change the text and background colors, the opacity, the frosted glass, the
  font, its weight, line spacing, width and alignment, the scrolling mode and the title bar.

**Also**
- White text by default: over a see-through background every letter takes its own color
  anyway.
- The glass and the letter colors are worked out several times faster.
- A slow click on the menu button no longer starts dragging the window instead of opening
  the toolbar.
- 1.6.0 was never published: on Linux the installed app showed no window at all. 1.6.1 is
  the same release with that fixed.

### Known issues

- The GNOME Shell extension is made for GNOME 51. Without it, or on other desktops, the
  prompter works with a plain background, and is not kept above other windows or hidden
  from screen sharing.
- The screen sharing portal only shares the main monitor, and its consent dialog is in
  English.
- Hiding from screen capture needs Windows 10 version 2004 or newer.
